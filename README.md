# Forguncy 직원 관리 데모

Forguncy(노코드 플랫폼)로 구현한 **직원 관리** 데모입니다.
직원 정보 입력·조회와 대시보드를 통한 직원 현황 파악 등 인사 관리 업무를 노코드로 구축한 예시를 확인할 수 있습니다.

## 🔗 데모 바로가기

👉 [데모 실행하기](https://demo.forguncy.co.kr/EmployeeSystem)

## 📋 주요 기능

- 직원 정보 등록·조회·수정
- 부서/직급별 직원 목록 조회
- 대시보드를 통한 직원 현황 확인 (인원수, 부서별 분포 등)

## 💾 Forguncy 다운로드

이 데모는 MESCIUS Forguncy로 제작되었습니다. 직접 열어보거나 커스터마이징하려면 아래에서 Forguncy를 다운로드하세요.

👉 [Forguncy 다운로드](https://www.mescius.co.kr/forguncy/download)

## ℹ️ Forguncy란?

Forguncy는 코딩 없이 드래그 앤 드롭 방식으로 웹 애플리케이션을 만들 수 있는 MESCIUS의 노코드 개발 플랫폼입니다. 직원 관리처럼 입력·조회·대시보드가 결합된 기본적인 인사 시스템도 Excel UI만으로 빠르게 구축할 수 있습니다.
